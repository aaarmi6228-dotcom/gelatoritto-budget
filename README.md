# gelatoritto-budget

Static Vercel deployment for the bookkeeping app.

## Setup

1. Open `supabase-config.js`.
2. Replace `REPLACE_WITH_SUPABASE_ANON_KEY` with the Supabase project's public anon key.
3. Deploy this folder to Vercel.

The anon key is intended for browser use. Keep the Supabase service-role key out of this project.
